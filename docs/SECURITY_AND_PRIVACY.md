# Public release safety and privacy review

## Scope

This repository is an **explicitly allowlisted static export**, not a copy of the source computer's folders. It contains original HTML/CSS/JS/SVG, the imaginary exhibit fixtures, intentionally broken BEFORE prototype, publicly understandable tests, and carefully selected test-result files.

It excludes local window-control scripts, terminal diagnostic tools, host/server implementation, configuration files, tokens, credentials, personal files, browser profiles, private repositories, unrelated projects, real visitor data, internal Guard implementation details, and the screen recording.

## Runtime

- No real user account, payment system, database, reservation backend or persistent visitor records.
- No external fonts, analytics, remote images, tracking pixels or third-party JavaScript.
- Site CSS and scripts use relative references compatible with a GitHub Pages repository subpath.
- The fictional reservation and feed-outage scenarios operate only in memory.
- Browser Content Security Policy blocks outbound fetch connections from the demo.
- Before and after pages remain deliberately different to demonstrate the seeded errors.

## Claims and limits

The browser and Node test assertions were genuinely executed. The presentation's saved evidence is explicitly historical; users can run the museum's checks again.

There has been no certified penetration test, complete WCAG audit, physical-device certification or review of the separate screen recording. Publication of the static demo does not approve publishing any raw recordings, system screenshots, or private operational tooling.

Use GitHub Issues for questions about this fictional demonstration. Do not submit real credentials, customer details or security tokens.
